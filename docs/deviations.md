# Deliberate deviations from vanilla

openblack replicates Black & White's logic and visuals exactly. This file lists every place where it **deliberately**
does something different, with who decided it, when, and where it lives. Gaps (vanilla behaviour not built yet) and
bugs do not belong here: they go in the progress tracker. Anything that differs from vanilla and is not listed here is
a bug to fix.

**Every deviation needs the user's sign-off** (user, 2026-10-11). Agents never deviate on their own: they implement
vanilla, and if they believe a deviation is needed they record it as PENDING here and ask the lead, who asks the user.
Only rows the user has approved are live.

**This file is version controlled** (user, 2026-10-12). It is the one canonical list; it moved here from bw1-decomp's
`docs/openblack/deviations.md`, which now only points here. A branch that adds, changes, signs off or withdraws a
deviation edits its row here in the same branch as the code, so the row and the code merge together. Rows are only
ever appended or edited in place, never renumbered: a number is kept for good, and a withdrawn or rejected row stays
with its reason. When two branches pick the same next number, the merge train renumbers the later one. The
`openblack-deviations` skill describes how to spot, record and get sign-off for a deviation.
