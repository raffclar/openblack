# Vanilla bugs: silver quests

Bugs in the original game's silver-scroll quest scripts on Lands 1 to 5, and in the shared scripts they use (the
creature swap offer). Quests the game never starts are included only under Harmless, where the bug is a plain mistake in
their script. Text-table typos in quest lines are in [interface_and_text.md](interface_and_text.md); the miracle
dispenser reward helper is in [miracles.md](miracles.md).

**Bugs: 71 (soft-locks and lost progress: 5)**
