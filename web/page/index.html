openblack plays Black & White in this browser tab. It needs the folder of your own install of Black & White.

The game data stays on this computer. The page reads the files in this tab and sends nothing to a server. The browser can show a message such as "Upload files to this site". That message is the standard text of the browser: the page does not send the files.

Or drop the Black & White folder here
