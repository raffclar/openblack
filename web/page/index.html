openblack plays Black & White in this browser tab. It needs the folder of your own install of Black & White.

openblack plays Black & White in this browser tab. The site sends the game files of your account to this browser, which keeps them for the next visit.

The game data stays on this computer. The page reads the files in this tab and sends nothing to a server. The browser can show a message such as "Upload files to this site". That message is the standard text of the browser: the page does not send the files. The "Send Crash Reports" box on the Options page of the game is set for a new profile. While it is set, the game sends its error and crash reports with the game log to Sentry, with no personal data. Clear the box to stop the reports. When you sign in, the box follows the privacy choice of your account on the site, and only the choice "with my name and address" adds your login name and address.
